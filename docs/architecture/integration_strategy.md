# OS Hub Integration Strategy (Activity Stream & MCP)

## חזון ארכיטקטוני: The Unified Activity Stream
מטרת העל של המערכת היא למנוע את "תסמונת 20 הטאבים הפתוחים". תיק הלקוח (ClientDetail) או המשימה צריכים לשאוב אוטומטית נתונים מכל ערוצי התקשורת ולהציג אותם כזרם פעילות מרכזי (Activity Feed) המשלב:
- שינויי סטטוס במסד הנתונים (DB History)
- בוט טלגרם (המנכ"ל הדיגיטלי)
- הודעות WhatsApp
- שרשורי אימייל (Gmail)
- פעילות קבצים (Google Drive)

## 1. אינטגרציית WhatsApp באמצעות MCP (Model Context Protocol)
**החלטה עסקית-טכנולוגית:** המערכת נמנעת משימוש ב-WhatsApp Business API או ספקי צד-שלישי יקרים (Twilio/GreenAPI), ומעדיפה גישה מבוססת MCP.
**איך זה עובד?**
1. סוכן (Agent) מקומי ניגש לפרוטוקול ה-MCP של דפדפן המשתמש בו רץ WhatsApp Web.
2. השרת שואב את התכתובות האחרונות לפי מספר הטלפון המוגדר בשדה `client.phone`.
3. הנתונים מתורגמים למבנה JSON סטנדרטי (Timestamp, Sender, Content) ומוצגים בזרם הפעילות עם תגית `[WhatsApp]`.
**יתרון:** אפס עלויות למטא (Meta), אין צורך בשרתי ענן לתיווך (Local-First).

## 2. אינטגרציית Telegram (הבוט "המנכ"ל הדיגיטלי")
- **התממשקות:** חיבור ישיר ל-Telegram Bot API באמצעות הטוקן הקיים, או חיבור למשתמש באמצעות MTProto.
- **טריגר:** המערכת שלנו (OS Hub) מאזינה ל-Webhooks או מבצעת Long Polling מול הבוט הקיים.
- **ביצוע:** פקודות (כמו `/tasks`, `/client`) ושיחות המבוצעות מול הבוט בטלגרם מסונכרנות בזמן אמת לתוך ה-Activity Stream של הלקוח הספציפי. בנוסף, המערכת יכולה "לירות" חזרה התראות לטלגרם על שינויי סטטוס.

## 2. אינטגרציית Gmail
- **התממשקות:** Google Workspace API דרך Service Account.
- **טריגר:** חיפוש בתיבת המייל הארגונית לפי `client.email`.
- **ביצוע:** הצגת Preview של השרשורים בזרם הפעילות (ללא שכפול המיילים במלואם ל-DB כדי לחסוך באחסון) יחד עם Deep-Link לפתיחת המייל בג'ימייל.

## 3. אוטומציית Google Drive
- **יצירת תיקיות אוטומטית:** בעת הוספת לקוח חדש ב-OS Hub, סריפט אוטומטי (Google Drive API) פותח תיקייה ייעודית בשם `[שם לקוח] - [ID]` תחת ספריית הלקוחות בארגון.
- המזהה (`folderId`) נשמר ברשומת הלקוח ב-DB.
- **ממשק משתמש:** לשונית "Drive" בתיק הלקוח מציגה Iframe (באמצעות Google Picker API) הממוקד רק בתיקיית הלקוח, ומאפשרת Upload/Download ישירות מהמערכת.

## 4. מנגנון הבקרה: Admin Dashboard
כל החיבורים הללו נשלטים מתוך אזור ניהול ייעודי במערכת ("הגדרות ואינטגרציות").
המשתמש (האדמין) יכול להדליק או לכבות את ממשקי ה-MCP וה-API באופן ויזואלי מבלי לגעת בקוד.
