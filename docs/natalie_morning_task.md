# משימה לביצוע: מיזוג לקוחות כפולים במורנינג
**נמען:** נטלי (מנכ"לית HUB OS)
**ערוץ מומלץ לשליחה:** אימייל (ceo@hub.co.il) / וואטסאפ

---

**נוסח ההודעה (לשליחה):**

היי נטלי,
במסגרת סריקת תקינות וסידור שרתים שביצענו, זיהינו שיש במערכת מורנינג מספר כפילויות של לקוחות שנוצרו על ידי אוטומציות או חיבורי API שונים. הכפילויות הללו מייצרות לעיתים חובות פתוחים (או חובות וירטואליים שאינם משויכים נכון ללקוח).

**מה נדרש לעשות?**
אנא היכנסי למערכת מורנינג (חשבונית ירוקה), היכנסי לכרטיסיית "לקוחות", סמני את הלקוחות הכפולים (כמו למשל כרטיסי מועדון הברידג' השונים) ולחצי על "מיזוג לקוחות". זה יאחד את כל המסמכים והחובות שלהם תחת קורת גג אחת, וייישר קו עם מאגר ה-SSOT שלנו. 

*(קיימת רשימה מפורטת של בעלי חובות שנוצרה על ידי המערכת לבקרה - רשימה של 30 כרטיסים).*
